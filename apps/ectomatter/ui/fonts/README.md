# Ectomatter's interface typefaces

The faces the window's own words are set in, built into Ectomatter. Each is
under the SIL Open Font License 1.1, its own copyright at the head of its
license file here.

- `Barlow-400.ttf`, `Barlow-500.ttf`, `Barlow-600.ttf`: https://github.com/jpt/barlow, OFL-1.1 (`Barlow-OFL.txt`).
- `BarlowSemiCondensed-500.ttf`, `BarlowSemiCondensed-600.ttf`: https://github.com/jpt/barlow, OFL-1.1 (`BarlowSemiCondensed-OFL.txt`).
- `Geist-400.ttf`, `Geist-500.ttf`, `Geist-600.ttf`: https://github.com/vercel/geist-font, OFL-1.1 (`Geist-OFL.txt`).

The licenses were taken from each project's own repository (Barlow's from
google/fonts, Geist's from vercel/geist-font) on 2026-10-27.
